# UI-рефакторинг: Tailwind CSS v4 и shadcn/ui

Дата: 2026-11-05. Изменения ограничены стилизацией Foundation.

## Что изменилось

- Tailwind CSS v4 и официальный `@tailwindcss/vite` подключены к Vite.
- shadcn/ui настроен через `components.json`; официальный CLI добавил Button,
  Input, Card, Badge, Table, Dialog, Select, Label (new-york, Radix, Lucide).
- Заглушки используют Card. Другие базовые компоненты подготовлены по требованию,
  без новых экранов, форм и бизнес-действий.
- Палитра, ширина оболочки 1040 px, отступы 24 px, структура меню и карточек сохранены.
- `globals.css` содержит только Tailwind, анимации, токены темы и глобальные правила.
  Типографика, layout, состояния ссылок и перенос длинных ID перенесены в JSX.
- Старый styles.css удалён. В приложении нет inline styles; динамическое
  позиционирование Radix управляется самой библиотекой.
- Удалены временно добавленные прямые зависимости clsx/tailwind-merge: актуальный
  генератор использует пакет cn. Новый собственный слой UI не вводился.
- Alias `@/` поддержан в TypeScript и Vite; Fast Refresh допускает стандартные
  экспорты вариантов только в файлах Button и Badge.

SQL, RLS, авторизация, API и бизнес-логика не изменялись. В текущем проекте эти
части ещё не реализованы. Конфигурация маршрутов, тексты и ID-параметры сохранены.

## Изменённые файлы

- `package.json`, `package-lock.json`: зависимости Tailwind/shadcn.
- `vite.config.ts`: Tailwind-плагин, alias.
- `tsconfig.json`, `tsconfig.app.json`: alias для shadcn.
- `eslint.config.js`: точечное разрешение экспортов вариантов shadcn.
- `components.json`: новый конфиг shadcn/ui.
- `src/app/globals.css`: новый глобальный файл и тема.
- `src/app/styles.css`: удалён.
- `src/main.tsx`: импорт globals.css.
- `src/app/App.tsx`: utility-классы оболочки и меню.
- `src/shared/ui/Placeholder.tsx`: shadcn Card, типографика.
- `src/pages/LoginPage.tsx`, `src/pages/ObjectsPage.tsx`,
  `src/pages/ObjectPage.tsx`, `src/pages/TaskPage.tsx`,
  `src/pages/MyTasksPage.tsx`, `src/pages/NotFoundPage.tsx`: локальные utility-классы.
- `src/components/ui/button.tsx`, `input.tsx`, `card.tsx`, `badge.tsx`,
  `table.tsx`, `dialog.tsx`, `select.tsx`, `label.tsx`: новые исходники shadcn/ui.
- `README.md`, `docs/adr/ADR-001.md`, `docs/ui-refactor.md`: описание стилизации и проверки.

## Проверки

- Установка Tailwind, зависимостей shadcn и генерация восьми компонентов CLI — успешно.
- `npm uninstall clsx tailwind-merge` — успешно; npm сообщил прежние
  10 moderate-предупреждений в зависимостях. Отдельный audit повторно не выполнялся.
- Поиск `rg` подтвердил отсутствие старых имён CSS-классов, импорта styles.css
  и `style=` в исходниках. Единственный CSS-файл приложения — globals.css.
- `npm run check` внутри sandbox — не запустился: `operation not permitted: npm`.
  Запрос на запуск этой команды вне sandbox отклонён; проверки текущей миграции
  не выполнялись. Предыдущие успешные проверки Foundation к ней не относятся.
- `npm run dev -- --host 127.0.0.1` вне sandbox — Vite запущен успешно.
  HTTP-проверки curl для globals.css и Placeholder.tsx — успешно, Tailwind
  генерирует CSS, компонент трансформируется Vite.
- Браузерная проверка недоступна: среда управления браузером завершилась при старте
  из-за sandbox-запрета чтения системной конфигурации OpenSSL. Адаптивность
  проверена только по коду (flex-wrap, ограничение ширины, перенос длинных ID);
  визуальная проверка на разных ширинах не выполнена.

Обязательные команды перед приёмкой:

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

Или `npm run check`. Не следует считать эти проверки пройденными до их запуска.

## Ручной smoke checklist

1. Выполнить `npm ci`, `npm run check`, `npm run dev`.
2. Открыть `/`: переход на `/objects`; прежние меню, фон, карточка и тексты.
3. Через меню открыть «Мои задачи», «Вход», «Объекты». Проверить активный пункт,
   браузерные «Назад»/«Вперёд» и видимый фокус ссылок через Tab/Enter.
4. Открыть `/objects/demo-object` и `/tasks/demo-task`, обновить страницу.
   Видны соответствующий заголовок и идентификатор.
5. Открыть неизвестный URL: страница 404 и рабочая ссылка «Перейти к объектам».
6. На ширинах 320, 375, 768 и 1280 px проверить все пять основных экранов и 404:
   нет горизонтального скролла, меню переносится, текст и карточка помещаются.
7. Проверить `/tasks/` с длинным ID без пробелов (например, 150 символов):
   ID переносится внутри карточки, не раздвигает страницу.
8. Проверить, что в Console нет ошибок, а в Network загружаются стили Tailwind.
9. После build запустить `npm run preview` и повторить прямой вход/обновление
   карточек и проверку мобильной ширины.

Button, Input, Badge, Table, Dialog, Select и Label ещё не используются экранами:
для них нет новых продуктовых сценариев. Их интерактивное поведение потребует
проверки при первом использовании. Тёмный режим не входит в текущий рефакторинг.
Коммиты и деплой не выполнялись.
